# Демонстрация олимпиады Алгоритмики

[Открыть демонстрацию](https://ustial.github.io/algoritmika-olympiad-demo/) · [Инструкция и вход](https://ustial.github.io/algoritmika-olympiad-demo/#/help)

Демо для знакомства коллег с интерфейсом. Развёрнуто на GitHub Pages; общий сервер и база данных не используются.

**Вход организатора:** логин `demo`, пароль `demo2026`. Это публичный условный вход, а не защита данных. Настоящие пароли и персональные данные не вводите.

## Как попробовать

1. Откройте сайт, выберите 3 класс и нажмите «Заполнить примером».
2. Подтвердите использование вымышленных данных, продолжите и нажмите «Начать олимпиаду».
3. Пройдите три задания, обновите страницу и убедитесь, что ответы сохранились.
4. Завершите тест. Затем войдите как организатор (`demo` / `demo2026`).
5. В «Результатах» выберите 3 класс: появится ваша попытка. Проверьте фильтры и CSV.
6. В «Олимпиадах» попробуйте редактирование заданий, баллов, порядка, длительности и публикации.

Подробная инструкция также доступна прямо на сайте по ссылке **«Инструкция и вход»**.

## Ограничения

- Каждый браузер хранит свою копию в localStorage. Коллеги не видят изменения и результаты друг друга.
- По общей ссылке передаётся исходная демонстрация; ваша отредактированная копия не передаётся.
- ФИО родителя и телефон из демонстрационной формы не сохраняются.
- Серверного контроля времени и настоящей авторизации в демо нет. Правильные ответы доступны в коде.
- Для реальной олимпиады используется отдельный Django-проект с PostgreSQL и серверной проверкой.
- Открывайте одну вкладку. Данные остаются после обновления, но исчезают при очистке хранилища. Сброс демо находится в инструкции.
- Вопросы и изображения редактируются локально. Изображения PNG/JPG/WebP — до 500 КБ, общий объём ограничен браузером.

## Сборка

В репозитории демо содержимое `site/` размещается в корне. Исходники TypeScript — в `src/`.

```sh
npm ci
npm run build
```

GitHub Pages публикует ветку `main`, папку `/ (root)`. Файл `.nojekyll` отключает Jekyll. Маршруты используют hash, поэтому ссылки работают и при размещении в подпапке репозитория.
